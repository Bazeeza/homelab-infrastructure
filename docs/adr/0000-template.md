# NNNN. Short title in the imperative

- **Status:** Proposed | Accepted | Deprecated | Superseded by NNNN
- **Decided:** YYYY-MM-DD
- **Applies to:** node-a, node-b, admin-ws

## Context

What situation forces a choice? Facts only: the constraint, the risk, what went wrong or could go wrong. No real names or addresses (see [anonymization rules](../anonymization.md)).

## Decision

The rule, in one or two sentences that start with "We will...". Then the details needed to apply it.

## Consequences

- **Positive:** what becomes safer, simpler or cheaper.
- **Negative:** what it costs: new dependency, extra step, single point of failure.
- **Follow-up:** what still has to be done for the decision to be fully applied.

## How to verify

Commands or checks that prove the decision is applied, with the expected result.

```bash
# Example

```
